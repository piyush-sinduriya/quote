QuoteDesk — quotation maker

Choose how to use it
• Install: run QuoteDesk-Setup.exe and follow the steps.
• Portable: keep QuoteDesk.exe, quotation-app.htm, Schooldecor-logo.png and QuoteDesk.ico together, then open QuoteDesk.exe.

Your computer keeps the working files in Documents\QuoteDesk:
• Settings — business details and quotation defaults.
• Product Catalog — products, photos, prices and GST rates.
• Quotations — current and saved drafts, plus one file for each saved quotation.
• PDFs — a backup PDF for every downloaded quotation.

Set up products once
Open Product catalog and add each product’s code, name, details, photo, price before GST and GST percentage. In a quotation, click the code or product name to browse the full catalog, choose a product, and enter the quantity. GST is calculated using that product’s own rate and shown separately in the quotation.

For a price list, import a CSV with these columns: code, name, spec, rate, gstRate. GST can be written as 18 or 18%. Download CSV to keep a separate catalog backup.

Save and share quotations
Your work is saved as a draft automatically while you type. Open Drafts in the sidebar to continue or remove a draft, including after refreshing the app. Choose Save & download PDF to save the quotation and download its PDF in one step. Download works even when quotation-app.htm is opened directly in Chrome. When QuoteDesk.exe is used, the same PDF is also backed up in Documents\QuoteDesk\PDFs, without the computer’s file location, date or app title printed on it.

Saved quotations have Preview, Download, Edit, Copy and Delete buttons. Download starts the PDF download directly and refreshes the backup PDF with the same quotation number.

Quotation data and PDFs stay on this computer. To move to another computer, install QuoteDesk there and copy the Documents\QuoteDesk folder, or use Back up my data and Restore backup.
